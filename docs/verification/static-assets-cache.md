# Исправление старых стилей после обновления

20 ноября 2026 года, ветка `fix/static-assets-cache` от `work` (`bfa2e73`).

## Причина и изменение

На пользовательском снимке новая разметка отображается со старым CSS:
фиолетовые кнопки, большой логотип, видимая skip-link, навигация без бокового
расположения. Сценарий воспроизведён с настоящими стилями до redesign
(`0ff5fec^:app/static/styles.css`) и текущей разметкой. Доступа к кэшу
пользовательского Chrome нет; происхождение конкретного ответа на его машине
не проверено, но воспроизведённый вид соответствует снимку.

Прежде `/static/styles.css` и скрипты имели неизменные URL. Ответ содержал
Last-Modified/ETag без явного Cache-Control, поэтому браузер мог считать
старую копию свежей после обновления HTML. Новый Chromium context, использованный
при прошлой проверке, не содержал такого кэша и не воспроизводил дефект.

Теперь все 38 ссылок на собственные ресурсы в шаблонах и ресурсы Swagger
получают `?v=<SHA-256 содержимого>`. При изменении файла меняется URL;
неизменное содержимое сохраняет прежний адрес. Префикс reverse proxy учтён.
Для статики, включая старые адреса и ответы 304, задан `Cache-Control: no-cache`:
допускается хранить копию, но перед повторным использованием нужно проверить её.
Локальные вложенные `__pycache__/*.pyc` дополнительно исключены из Docker context.

Браузерный прогон использует новый изолированный PostgreSQL database и host API
с теми же файлами, которые проверены в Docker-образе. Полный новый Compose-проект
не поднимался: VFS Docker на этом стенде требует полного копирования rootfs,
а свободное место нужно сохранить выше media reserve основного сервиса.
Основные `.env`, контейнеры, база и media не обновлялись. Временная БД удалена,
временный образ и только созданные этой проверкой build-cache записи очищаются.

`/tmp/static-cache-docker-build-final.log`,

```bash
STATIC_TEST_BASE_URL=http://127.0.0.1:8080 node experiments/static_cache_browser_probe.cjs
```

Нужны Node/Playwright, `/usr/bin/chromium` и история Git с доредизайновым CSS.
Проба создаёт собственный loopback proxy и новый каталог результатов в `/tmp`,
выполняет только GET к целевому приложению, не меняет его данные.

Для старой сборки немедленный обход — Ctrl+Shift+R (на macOS Cmd+Shift+R).
После получения исправленного кода пересоберите через `bash scripts/start.sh`.
