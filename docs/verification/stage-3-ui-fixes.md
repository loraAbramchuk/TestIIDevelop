  Допустимое имя из 100 букв без пробелов больше не расширяет мобильную страницу.
- `/docs` использует локальные JS, CSS и favicon Swagger UI 5.35.0. Онлайн-валидатор
  отключён. Добавлены неизменённые upstream-ресурсы, Apache-2.0 LICENSE/NOTICE и
  лицензии зависимостей bundle. SHA-512 архива сверена с npm distribution integrity;

## Повторная сквозная проверка

Основной экземпляр с коммитом b64c6dd проверен на совпадение файлов приложения
с checkout. Полный pytest повторно дал 113 passed; alembic check не нашёл
расхождений. Для браузерных операций создан отдельный свежий Compose-контур.

Проверены вход/выход и отзыв сессии, неверный пароль, сохранение сессии после
reload, карточки, изменение метаданных, выдача/отзыв grants, запрет чужого
управления, размер, обрыв TCP и передача через Nginx. Swagger отрисовал все
17 операций и выполнил Try it out без внешних запросов. Имя из 100 символов
прошло ширины 320/390/768/1440 px.

Уточнены два места самого браузерного сценария:

- После 415 сценарий ждёт завершения сверки статуса и скрытия кнопки отмены,
  прежде чем проверять доступность редактирования. Сообщение об ошибке появляется
  раньше этой асинхронной операции, поэтому прежняя проверка иногда спешила.
- В симуляции потерянного ответа передаются байты известного файла напрямую:
  Chromium может не предоставлять postData перехваченного файлового запроса.
  Передача null в route.fetch создавала тестовый payload `null` вместо MP4.

После исправления сценарий прошёл через Nginx. Оба сохранённых файла — обычная
загрузка и потерянный ответ — имеют 73 941 байт и SHA-256 исходного MP4. Для
каждого есть ровно одно соответствующее задание todo. Прерванная попытка очищена
с освобождением резерва; ранний 413 не создаёт попытку и не резервирует место.
Код приложения в этой повторной проверке не изменялся.
