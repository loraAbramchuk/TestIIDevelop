## Поведение после исправлений

- **A1, подготовка загрузки.** CSRF перед отправкой файла получает тот же
  ограниченный по времени `apiRead`, что другие запросы: 15 секунд на заголовки
  и чтение тела. После ошибки подготовки выбор файла/отправка разблокируются,
  файл и метаданные сохраняются, статус объясняет ошибку. Если передача ещё
  не началась, дополнительная проверка статуса не задерживает восстановление
  формы. После начала передачи сверка состояния сохранена. Таймаут большого
  файла не заменён коротким таймаутом подготовки.
- **A2, обсуждение/плейлист/разрешения.** Собственные GET переведены на `apiRead`.
  Сохраняются HTTP status/code и признак ошибки чтения плейлиста, поэтому
  отсутствие плейлиста и потеря доступа обрабатываются как прежде.
  После таймаута доступны повторное обновление и редактирование; настоящий
  черновик названия плейлиста не затирается.
- **A3, комментарий.** До очистки поля проверяются идентификаторы комментария
  и видео, текст, дата, автор и признак возможности удаления своего комментария.
  Неполный ответ больше не подтверждает публикацию: текст сохраняется,
  предлагается обновить обсуждение. Проверяются также данные лайков и страниц
  комментариев. После потери ответа на фактически сохранённый комментарий
  GET показывает результат без автоматического повтора POST.
- **A4, HTML-ошибки.** Валидация ссылок `/watch/` и `/studio` возвращает
  оформленную страницу. Доменные ошибки HTML-экранов тоже отображаются как HTML;
  исходные 400/404/422 сохраняются. API продолжает возвращать JSON с прежними
  статусами и кодами, недоступные видео не раскрываются.
- **A5, доступность ссылки.** Постоянное имя «Загрузить видео» доступно
  экранному диктору при скрытом мобильном тексте. Видимая подпись «Загрузить»
  входит в доступное имя и подходит для голосового управления. Проверяется
  как `link-name`, так и `label-content-name-mismatch`.

Обновлён [чек-лист приёмки](../acceptance.md): отмечены реализованные и
подтверждённые сценарии, даны ссылки на отчёты. Приёмка чистой Ubuntu VM
и публичного HTTPS с предоставленным доменом осталась отдельно неотмеченной.
