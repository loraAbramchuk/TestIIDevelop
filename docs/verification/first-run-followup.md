# Исправление трёх замечаний повторной проверки

23 ноября 2026 года, ветка `fix/first-run-registration-seed`, база `33c7fe6`.

## Что изменено

1. После подготовки ключа launcher перечитывает эффективную конфигурацию
   Compose. Для локального запуска пустой inherited `AUTH_MAIL_SECRET` удаляется
   только из окружения дочерних Compose-команд: используется ключ из `.env`.
   Окружение вызывающего процесса и непустые overrides сохраняются. Ключ
   проверяется до сборки/остановки сервисов; диагностика запущенного app должна
   подтвердить настройку почты до объявления готовности и старта web.
   Неполная явно выбранная SMTP-конфигурация даёт ранний отказ.
2. В README согласованы адреса API и worker: все три host-процесса запускаются
   с `PUBLIC_BASE_URL=http://localhost:8000`. Добавлены явные команды worker
   и maintenance, необходимые для писем, обработки и восстановления заданий.
   Для host-разработки выделен отдельный Compose-проект БД/Mailpit; описаны
   остановка полного стека и раздельное хранение media.
3. Сессия seed покрывает суммарное ожидание всех роликов, upload/финальный poll
   и небольшой запас. Минимум остаётся 10 минут; максимум при четырёх видео
   и `--timeout 600` — 43 минуты. В finally удаляется только служебная сессия.

## Подтверждения

- Полная регрессия с отдельной PostgreSQL-БД: **586 passed, 0 failed,
  0 skipped**, 185,38 с. Единственное предупреждение — прежнее upstream
  StarletteDeprecationWarning о TestClient/httpx.
- Целевые unit-проверки launcher/config/operations: **69 passed**.
- Новый DB-тест моделирует четыре задания по 590 секунд. После каждого
  контролируемого сдвига UTC выполняется настоящий `GET /api/auth/me` через
  cookie и реальный PostgreSQL: все четыре запроса успешны после суммарных
  39 минут 20 секунд. По завершении служебная сессия удалена, остальные записи
  сессий сохранены. В этом тесте медиа-транспорт контролируется; реальные MP4
  отдельно проверены сквозным Docker seed.
- Полный Compose со свежими volumes, штатными Dockerfile, UID и лимитами:
  **первый старт с `AUTH_MAIL_SECRET=''` прошёл**. Регистрация 201, вход до
  подтверждения 200, реальные письма Mailpit, подтверждение и восстановление.
  Проверены два seed без дублей, четыре роли, приватный доступ, MP4 Range 206,
  регистрация через UI и перезапуск с сохранением env/хеша видео.
- Host-сценарий API + worker + maintenance проверен на изолированном порту
  18000 с единым PUBLIC_BASE_URL. Письмо содержит правильный origin, страница
  подтверждения доступна, подтверждение 200. SMTP-провайдер не требовался.
- Ruff check/format, экспорт API-контракта, uv lock --check --offline и
  git diff --check выполнены.

Тестовые volumes/контейнеры и host-БД/процессы очищены, основной стек,
