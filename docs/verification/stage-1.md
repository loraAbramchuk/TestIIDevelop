## Границы результата

- Не реализованы видео-модель, ACL видео, рабочая загрузка, FFmpeg-worker,
  фактическое ограничение квот, восстановление настоящих файлов и Nginx stream endpoints.
- Readiness/diagnostics не называют отсутствующий worker работающим:
  processing=not_configured, video_uploads=not_implemented.
- Повтор после SIGKILL подтверждён на синтетическом задании. Публикация файлов,
  fencing устаревшего живого worker, удаление во время обработки — этап 4.
- Проверка Chromium подтверждает два образца, а не все допустимые файлы и устройства.
- Firefox не установлен: download вернул `403 Domain forbidden` для
  `playwright.download.prss.microsoft.com`. Safari/WebKit и мобильные устройства
  не запускались. Их поддержка не заявляется.
- Проверка перемотки выполнена на HTTP-сервере образцов с Range; будущая
  защищённая Nginx-раздача проверяется отдельно на этапе 5.
