# Простой интерфейс видеоплатформы

Ветка `feature/youtube-style-frontend` создана от `work` (`6a401a4`).
Серверные Jinja2-шаблоны, локальные CSS/SVG и обычный JavaScript; отдельная
сборка фронта, npm, React и внешние CDN не нужны. API, роли и схема БД сохранены.

## Что изменено

- Светлая шапка с поиском, знаком воспроизведения, созданием видео и меню аккаунта.
- Боковая навигация с активным разделом. Moderator/admin видят свои пункты;
  при потере роли серверные ограничения остаются основным источником прав.
- Главная: адаптивная сетка реальных видео, автор/аватар, дата и длительность.
  Пустая лента содержит предложение загрузить первое видео.
- Просмотр: нативный плеер, автор, описание, лайки/комментарии и жалобы;
  справа/ниже — другие публичные видео из существующего `/api/videos`.
  Предложения не являются персональной рекомендательной системой. Есть таймаут,
  понятная ошибка и повтор загрузки; текущее видео исключено.
- Баннер и аватар канала; начальная буква обновляется при переименовании.
- Динамические карточки плейлиста выглядят так же, как серверные; порядок и права
  продолжают обрабатываться существующим API.
- На телефоне поиск вынесен во вторую строку, сетка становится одноколоночной.
  Меню закрывается Escape/фоном, удерживает клавиатурный фокус; основной контент
  становится inert, после закрытия фокус возвращается к кнопке. Учтён reduced motion.
- Отправка формы авторизации без JavaScript использует POST: пароль не попадает
  в URL. Сам вход/регистрация, как прежде, требуют JavaScript (есть noscript-пояснение).

Нет вымышленных просмотров, жанров, уведомлений или сохранённых демонстрационных
видео в основной ленте. Статистика и контент показываются только из API.
