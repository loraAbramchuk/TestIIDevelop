# Сценарии приёмки

Это план проверок, а не отчёт об их выполнении. На момент создания документа приложение и тесты отсутствуют. Каждому пункту при реализации назначается автоматический тест либо документированная ручная проверка.

## Видео и хранение

- [ ] Допустимый MP4 загружается; метаданные и превью появляются после обработки.
- [ ] Интерфейс различает прогресс передачи и последующую обработку; ошибка видна пользователю.
- [ ] Несоответствующие расширению данные, неподдерживаемые кодеки, пустой и слишком большой файл отклоняются.
- [ ] Обрыв загрузки не создаёт готовое видео; временные файлы удаляются.
- [ ] При недостатке места возвращается понятная ошибка без повреждения других видео.
- [ ] Параллельные загрузки получают разные ключи и не перезаписывают файлы друг друга.
- [ ] После перезапуска HTTP-сервиса, обработчика и БД видео остаётся доступным; незавершённая обработка корректно восстанавливается или получает явный статус ошибки.
- [ ] Браузер воспроизводит видео со звуком и перематывает в середину; запрос диапазона возвращает 206 с правильными байтами и Content-Range, недопустимый диапазон — 416.
- [ ] Удаление владельцем убирает видео из выдачи, освобождает файл и превью; старые ссылки не работают.

## Доступ и роли

Для проверок используются гость, владелец, пользователь с разрешением, пользователь без разрешения, модератор и администратор.

- [ ] Регистрация не позволяет выбрать привилегированную роль; пароль хранится как безопасный хеш.
- [ ] Вход и выход работают; завершённая сессия больше не предоставляет доступ.
- [ ] Запрос изменения состояния без требуемой CSRF-защиты отклоняется при cookie-сессии.
- [ ] Пользователь не может менять чужие метаданные, канал, плейлисты, приватность и разрешения или удалять чужое видео.
- [ ] Приватное видео доступно владельцу и конкретному получателю разрешения.
- [ ] Гость и пользователь без разрешения не получают приватные метаданные, файл, диапазон файла, превью, комментарии и счётчики по прямому URL или через API.
- [ ] Роли модератора и администратора без разрешения владельца не открывают приватный файл.
- [ ] Выдача доступа одному аккаунту не открывает видео другим аккаунтам.
- [ ] После отзыва разрешения новые запросы видео, диапазонов и превью отклоняются.
- [ ] При смене public на private новые запросы без разрешения отклоняются, а общие кэши не раскрывают контент.
- [ ] Прямой внешний URL внутреннего Nginx-хранилища не отдаёт файл.
- [ ] Обычный пользователь не имеет доступа к жалобам других пользователей, модерации и назначению ролей. Модератор не может назначать роли.
- [ ] Назначение роли администратором меняет права целевого аккаунта без возможности самоназначения через профиль.

## Экраны и взаимодействия

- [ ] Главная показывает превью готовых публичных видео, пагинацию и корректное пустое состояние.
- [ ] Поиск находит часть названия без учёта регистра и не показывает приватные, скрытые и неготовые ролики.
- [ ] На странице просмотра работают плеер, описание, переход на канал, лайки, комментарии и жалоба.
- [ ] Пользователь может поставить и снять лайк; повторные и параллельные запросы не создают дубликаты.
- [ ] Комментарий виден после публикации; его автор может удалить его; HTML и скрипты показываются как текст.
- [ ] Канал отображает видео и плейлисты автора; недоступные видео не раскрываются.
- [ ] Подписка и отмена работают; дубликаты и подписка на себя запрещены.
- [ ] Владелец управляет своим плейлистом и порядком видео; другой пользователь изменить его не может.
- [ ] Публичный плейлист с приватным видео не раскрывает его посетителю без разрешения.
- [ ] Формы регистрации, входа и загрузки показывают ошибки и не теряют безопасные введённые данные при исправимых ошибках.

## Модерация

- [ ] Пользователь подаёт жалобу на доступное видео; повторная открытая жалоба не создаёт дубликат.
- [ ] Модератор видит очередь и может закрыть либо отклонить жалобу.
- [ ] Скрытие немедленно убирает видео из ленты, поиска, канала и плейлистов; новые запросы файла и превью запрещены, в том числе владельцу.
- [ ] Владелец видит причину скрытия в управлении загрузками и не может обойти её редактированием видео.
- [ ] Восстановление возвращает доступ по исходной приватности, не делая приватное видео публичным.
- [ ] Для скрытия и восстановления сохраняются причина, исполнитель и время.

## Деплой и эксплуатация

- [ ] На чистой Ubuntu 24.04 LTS одна документированная команда поднимает стек и применяет миграции.
- [ ] `/docs` содержит действующую спецификацию API и ответы об ошибках.
- [ ] Проверка готовности обнаруживает недоступную БД, хранилище и обработчик.
- [ ] Повторная установка и перезапуск сохраняют базу и видео; секреты не заменяются молча.
- [ ] Инструкция HTTPS проверена с доменом и DNS, предоставленными владельцем сервера.
- [ ] Резервная копия базы и файлов восстанавливается отдельно; восстановленное видео воспроизводится с правильными правами доступа.
- [ ] Секреты, пароли и сессии не попадают в Git и логи.
- [ ] Тестовый отчёт отдельно показывает пройденные, проваленные, пропущенные и ещё не выполненные проверки.
