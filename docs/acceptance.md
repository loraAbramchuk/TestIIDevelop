ещё не выполненную приёмку на целевой инфраструктуре. Ограничения среды
не считаются подтверждённой проверкой чистой VM или публичного домена.

## Видео и хранение

- [x] Допустимый MP4 загружается; метаданные и превью появляются после обработки.
- [x] Интерфейс различает прогресс передачи и последующую обработку; ошибка видна пользователю.
- [x] Несоответствующие расширению данные, неподдерживаемые кодеки, пустой и слишком большой файл отклоняются.
- [x] Обрыв загрузки не создаёт готовое видео; временные файлы удаляются.
- [x] При недостатке места возвращается понятная ошибка без повреждения других видео.
- [x] Параллельные загрузки получают разные ключи и не перезаписывают файлы друг друга.
- [x] После перезапуска HTTP-сервиса, обработчика и БД видео остаётся доступным; незавершённая обработка корректно восстанавливается или получает явный статус ошибки.
- [x] При остановленном worker готовые видео продолжают воспроизводиться; новые загрузки принимаются только в пределах лимитов очереди и места либо получают понятный отказ.
- [x] Браузер воспроизводит видео со звуком и перематывает в середину; запрос диапазона возвращает 206 с правильными байтами и Content-Range, недопустимый диапазон — 416.
- [x] Удаление владельцем убирает видео из выдачи, освобождает файл и превью; старые ссылки не работают.

## Доступ и роли

Для проверок используются гость, владелец, пользователь с разрешением, пользователь без разрешения, модератор и администратор.

- [x] Регистрация не позволяет выбрать привилегированную роль; пароль хранится как безопасный хеш.
- [x] Вход и выход работают; завершённая сессия больше не предоставляет доступ.
- [x] Запрос изменения состояния без требуемой CSRF-защиты отклоняется при cookie-сессии.
- [x] Открытая регистрация создаёт неподтверждённый аккаунт; письмо позволяет одноразово подтвердить email перед изменением контента.
- [x] Восстановление не раскрывает наличие адреса; одноразовая смена пароля завершает все старые сессии, включая конкурирующий вход.
- [x] Пользователь не может менять чужие метаданные, канал, плейлисты, приватность и разрешения или удалять чужое видео.
- [x] Приватное видео доступно владельцу и конкретному получателю разрешения.
- [x] Гость и пользователь без разрешения не получают приватные метаданные, файл, диапазон файла, превью, комментарии и счётчики по прямому URL или через API.
- [x] Роли модератора и администратора без разрешения владельца не открывают приватный файл.
- [x] Выдача доступа одному аккаунту не открывает видео другим аккаунтам.
- [x] После отзыва разрешения новые запросы видео, диапазонов и превью отклоняются.
- [x] При смене public на private новые запросы без разрешения отклоняются, а общие кэши не раскрывают контент.
- [x] Прямой внешний URL внутреннего Nginx-хранилища не отдаёт файл.
- [x] Обычный пользователь не имеет доступа к жалобам других пользователей, модерации и назначению ролей. Модератор не может назначать роли.
- [x] Назначение роли администратором меняет права целевого аккаунта без возможности самоназначения через профиль.

## Экраны и взаимодействия

- [x] Главная показывает превью готовых публичных видео, пагинацию и корректное пустое состояние.
- [x] Поиск находит часть названия без учёта регистра и не показывает приватные, скрытые и неготовые ролики.
- [x] На странице просмотра работают плеер, описание, переход на канал, лайки, комментарии и жалоба.
- [x] Пользователь может поставить и снять лайк; повторные и параллельные запросы не создают дубликаты.
- [x] Комментарий виден после публикации; его автор может удалить его; HTML и скрипты показываются как текст.
- [x] Канал отображает видео и плейлисты автора; недоступные видео не раскрываются.
- [x] Подписка и отмена работают; дубликаты и подписка на себя запрещены.
- [x] Владелец управляет своим плейлистом и порядком видео; другой пользователь изменить его не может.
- [x] Публичный плейлист с приватным видео не раскрывает его посетителю без разрешения.
- [x] Формы регистрации, входа и загрузки показывают ошибки и не теряют безопасные введённые данные при исправимых ошибках.

## Модерация

- [x] Пользователь подаёт жалобу на доступное видео; повторная открытая жалоба не создаёт дубликат.
- [x] Модератор видит очередь и может закрыть либо отклонить жалобу.
- [x] Скрытие немедленно убирает видео из ленты, поиска, канала и плейлистов; новые запросы файла и превью запрещены, в том числе владельцу.
- [x] Владелец видит причину скрытия в управлении загрузками и не может обойти её редактированием видео.
- [x] Восстановление возвращает доступ по исходной приватности, не делая приватное видео публичным.
- [x] Для скрытия и восстановления сохраняются причина, исполнитель и время.

## Деплой и эксплуатация

- [ ] На чистой Ubuntu 24.04 LTS одна документированная команда поднимает стек и применяет миграции.
- [x] `/docs` содержит действующую спецификацию API и ответы об ошибках.
- [x] Диагностика различает недоступность БД, хранилища и обработчика; готовность просмотра не зависит от состояния worker.
- [x] Повторная установка и перезапуск сохраняют базу и видео; секреты не заменяются молча.
- [ ] Инструкция HTTPS проверена с доменом и DNS, предоставленными владельцем сервера.
- [ ] Выбран и проверен production SMTP-провайдер; canonical HTTPS origin и доставляемость подтверждены на целевом домене.
- [x] Резервная копия базы и файлов восстанавливается отдельно; восстановленное видео воспроизводится с правильными правами доступа.
- [x] Секреты, пароли и сессии не попадают в Git и логи.
- [x] Тестовый отчёт отдельно показывает пройденные, проваленные, пропущенные и ещё не выполненные проверки.
